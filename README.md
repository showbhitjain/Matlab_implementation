## 📌 Overview

This repository (`Matlab_implementation`) contains MATLAB functions used to generate C++ code via **MATLAB Coder**.  
The generated code is integrated into my Master’s thesis project:

👉 [**TUM_SJ_ObstacleAvoidanceLib**](https://github.com/showbhitjain/TUM_SJ_ObstacleAvoidanceLib)  
*An obstacle avoidance framework for serial-chain manipulators.*

To understand which MATLAB functions are used for C++ code generation and how they are integrated into the control architecture, please refer to the documentation in the `TUM_SJ_ObstacleAvoidanceLib` repository.
