## 🧩 Purpose

This repository serves as a support library for generating C++ code from selected MATLAB functions.  
These generated functions are integrated into the main project:

👉 [**TUM_SJ_ObstacleAvoidanceLib**](https://github.com/showbhitjain/TUM_SJ_ObstacleAvoidanceLib)  
*An obstacle avoidance framework for serial-chain manipulators.*

Please refer to the main repository to see which MATLAB functions from this repo are used for C++ code generation and how they are integrated into the overall control architecture.
